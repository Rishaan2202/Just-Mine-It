# Just-Mine-It
<h2>A really cool mining game made in Godot!</h2>
<br>
<h2>This is basically a game based on mining, where you (the chracter ofc) mine down and down and down! The more you mine, the more you earn (not real money ofc). The rarer ore you mine, the MOREer you earn! Pretty basic and fun game tbh!</h2>
